Your agent asks.You nod.

Nod is the approval screen for AI agents on Solana Mobile. When an agent wants to spend, your phone shows what the transaction really does. Your wallet signs. The agent never holds the key.

Download for Android Watch the demo

Free. Android 7 or newer. Open the app and tap Try demo, no wallet needed.

The agent never holds your key

Agents can only ask. Your wallet, and on Seeker the Seed Vault, is the only thing that can sign.

The screen shows the truth

Every request is simulated against the chain. You see what will actually leave your wallet, whatever the agent claims.

You set the limits

Small repeat payments can flow up to a daily limit. Anything new, large or odd waits for you. One switch pauses every agent.

From request to signature in one tap

Nod sits between your agents and your wallet. It never moves money on its own.

  1. Your agent asksClaude Code, Cursor, Codex or OpenClaw calls Nod's MCP tool.
  2. The relay deliversOver HTTPS to the phone you paired by QR code. It never sees a key.
  3. You reviewReal amount, recipient, fee and any warning, on one card.
  4. Your wallet signsThrough Mobile Wallet Adapter, in the wallet you already use.
  5. The agent hears backA signature on Solana, or a clear no.

One inbox for every agent you run

Nod ships an MCP server, so any agent that speaks MCP can ask. Each request shows which agent sent it and from which laptop.

# pair once: scan the QR code with Nod
npm run pair -- --relay https://relay.ajkadri.dev

# then add Nod to your agent's MCP config
{
  "mcpServers": {
    "nod": {
      "command": "node",
      "args": ["agent/mcp-server.js"],
      "env": { "AGENT_NAME": "Research agent" }
    }
  }
}

Built so the worst case is a no

Pairing by one-time QR code
The relay stores only fingerprints of keys. A photo of the code is useless after pairing.
One phone per pairing
A request can't be shown to two phones, so it can't be signed twice.
Nothing signed for nobody
If the agent withdraws a request, it disappears from your phone before you can approve it.
Approve late, still lands
Nod refreshes old transactions before signing, so a request that waited minutes still goes through.
Auto-approve with hard rules
Only plain transfers, only to addresses you've approved yourself, never with a warning, never over your daily limit.
Open source
Every rule above is in the code and covered by tests. Read it on GitHub.
